# Portafolio de Ciencia de Datos | Bryan Hossain Felex

Este repositorio reúne proyectos de análisis de datos y Machine Learning desarrollados durante mi formación en TripleTen.

## Proyectos

| Proyecto | Objetivo | Resultado destacado |
|---|---|---|
| [Predicción de abandono bancario](proyectos/prediccion_abandono_bancario.ipynb) | Identificar clientes con riesgo de abandono | Random Forest balanceado: F1 0.5962 y AUC-ROC 0.8484 en test |
| [Movilidad en Chicago](proyectos/analisis_movilidad_chicago.ipynb) | Analizar demanda de taxis y relación entre clima y duración | Diferencia significativa con p = 1.33e-11; clima adverso asociado a +6.89 min |
| [Mercado de videojuegos](proyectos/analisis_mercado_videojuegos.ipynb) | Orientar campañas con ventas, plataformas y preferencias regionales | PS4 con mayor potencial; diferencias relevantes entre occidente y Japón |

## Herramientas

Python · SQL · Pandas · NumPy · Matplotlib · Plotly · SciPy · scikit-learn · Render

## Ejecución

```bash
pip install -r requirements.txt
jupyter notebook
```

> Los notebooks proceden de un entorno académico de TripleTen. Para ejecutarlos fuera de ese entorno, añade los datasets necesarios en una carpeta `data/` y actualiza las rutas de carga.
